# Screenshot assets

These are unedited window captures of apps 0.4.0, taken on macOS on November 9, 2026.
They show actual installed metadata; counts, versions, and paths are examples, not product guarantees.
The application UI is English by default; these captures use English. Russian remains available in Settings → Language.

| File | View |
| --- | --- |
| `npm-environments.jpg` | Global packages from several Node.js installations and a scoped package detail |
| `python-venv.jpg` | Project venv filter and the exact interpreter of the selected Python distribution |
| `go-tool-details.jpg` | Go inventory and gopls build/module details |

Capture through the native UI without running package upgrades or removals. Avoid credentials,
private registry URLs, unrelated windows, and logs containing secrets. Keep the full relevant
window and verify labels/details are readable. Do not fabricate packages or modify the screenshot
to imply features or localization that the app does not have.

A macOS window-sharing indicator occupies the traffic-light area during capture. It is system UI;
apps retains native close, minimize, and fullscreen controls. Capture did not change system appearance.
