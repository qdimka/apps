# Categories and environment inventory — corrected design

User clarification supersedes the source-dropdown/no-sidebar design. Keep Homebrew, uv, pipx, npm, pip, Go and Cargo categories in the sidebar plus All packages. For npm and pip aggregate all discovered and manually added runtimes, rather than one active runtime. Each row labels its Node installation or Python environment. A dropdown above the list filters environments without changing installed state or manager configuration. Identical package names in distinct runtimes remain distinct and mutations dispatch to the exact interpreter/npm path. A failed runtime must not hide healthy runtimes or allow operations on stale rows.

Approach: extend existing coordinator to multiple managers per source with per-runtime states and aggregate source states. RuntimeDiscovery includes bounded project venv discovery under conventional development directories; manual addition remains for arbitrary locations. Labels include unambiguous path context, full paths remain available. No automatic installation or environment activation. Existing Go/Cargo work remains; close outstanding review findings as part of final verification.
