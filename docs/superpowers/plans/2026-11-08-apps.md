# Initial apps implementation plan

**Status:** Completed historical 0.1 plan, condensed for reference. Current commands and contracts
are in [AGENTS.md](../../../AGENTS.md) and [architecture.md](../../architecture.md).

**Goal:** A free local macOS app for inspecting, upgrading, and removing Homebrew, uv tools, and pipx packages.
**Design:** [Initial specification](../specs/2026-11-08-cli-manager-design.md).
**Stack:** Swift 6, SwiftUI, Foundation/POSIX, Swift Package Manager, local app packaging.

## Constraints

Use the user-selected name apps, macOS 14+, current-user commands without sudo, serialized changes,
independent source reads, no account/cloud/analytics/paid service, and no real package mutations in tests.
Unknown optional metadata must not block inspection.

## Completed tasks

1. **Models and runner:** Add composite identities and injected CommandRunning. Check equal names across
   sources, literal arguments with spaces/shell characters, large stdout/stderr, nonzero exits, cancellation,
   and deadlines. Implement without shell concatenation and commit after verification.
2. **Discovery and adapters:** Verify CLI formats with official help and read-only fixtures. Implement
   PATH/standard-location discovery and Homebrew/uv/pipx parsing. Check empty/malformed responses,
   formula/cask records, pipx commands, uv text, and unknown update availability. Never substitute an
   installation operation for a version check. Verify available real managers by inventory only.
3. **Coordinator and UI:** Test partial failures, repeated actions, failed mutations, and affected-source
   refresh. Build source sidebar, searchable list, details, log, removal confirmation, restrictions,
   and accurate status. Persist preferences. Inspect the native window without real uninstalls.
4. **Local bundle:** Package dist/apps.app, Info.plist, icon, and ad hoc signature. Document build/run
   behavior, ignore generated output, compile release, validate signature/plist, and inspect the launched app.

## Files and interfaces

PackageRecord and CommandResult define identity/metadata and exit/stdout/stderr. PackageManager exposes
list/checkUpdates/upgrade/uninstall with executable and runner injection. PackageCoordinator is testable
without SwiftUI; AppModel adapts it for the views. Sources are under Sources/AppsCore and Sources/Apps;
checks under Tests/AppsCoreTests; packaging under scripts and Resources.

## Execution outcome and deviations

The original proposal used XCTest/swift test and Foundation Process. The delivered executable
AppsCoreChecks runs via scripts/test.sh because full XCTest is absent in Command Line Tools.
The runner evolved to POSIX process groups. Final 0.1 review fixes passed 33 checks. Homebrew checks
use local metadata, not brew update, because update can migrate installations. Dark appearance was
inspected; light appearance uses semantic system colors but was not separately inspected.
See [validation evidence](../../validation.md) for detailed limits and later releases.
