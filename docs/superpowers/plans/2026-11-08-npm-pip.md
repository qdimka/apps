# npm and pip implementation plan

**Status:** Completed historical 0.2 plan. The single-active-runtime UI was superseded by
[environment inventory](2026-11-08-environment-inventory.md).
**Design:** [npm/pip specification](../specs/2026-11-08-npm-pip-design.md).

**Goal:** Add global npm and Python distributions from a main interpreter or project venv.
**Architecture:** Inject PackageManager adapters through CommandRunning. RuntimeDiscovery finds
installations; the original AppModel stored one active runtime for each source.
**Stack:** Swift 6, macOS 14+, SwiftUI, Foundation/POSIX, importlib.metadata, existing npm/pip.

## Constraints and review focus

No new dependencies, sudo, forced system-package overrides, or real mutations during tests.
Serialize changes; keep source reads independent and native window controls unduplicated.
Preserve scoped names, npm exit-code semantics, origins, venv symlink identity, and ownership.
Removal confirmation must describe the exact package/environment; runtime settings must not change
an operation's target while it is executing.

## Completed tasks

1. **Global npm:** Extend sources/kinds/restrictions and implement NPMManager. Test global/scoped/link
   parsing, outdated exit 1, malformed/error JSON, explicit prefix, stale context, and self-removal.
   Initially proposed package@latest; final review required SemVer comparison and an exact newer target.
2. **pip and discovery:** Implement a static standard-library metadata probe and exact python -m pip
   commands. Test normalized names, system/external/Conda/foreign ownership, missing pip, editable
   origins, index responses, nvm default, and venv symlinks. Add standard Python/Conda/nvm discovery
   and manual venv selection. Read real npm/Python inventory without changing installations.
3. **Native settings and details:** Add runtime replacement in the coordinator, persisted choices,
   native file/venv dialogs, exact removal explanation, and restrictions. Check runtime-switch isolation
   and busy guards. Package 0.2.0, verify signatures/plist, inspect UI, document limits, and review.

Each implementation task followed failing checks, implementation, full scripts/test.sh verification,
and a commit. Key files: NPMManager.swift, PipManager.swift, RuntimeDiscovery.swift,
PackageCoordinator.swift in Sources/AppsCore; AppModel.swift, SourceSettingsView.swift,
ContentView.swift, PackageDetailView.swift in Sources/Apps; corresponding executable checks.

## Final safeguards

Review added pip configuration-scope rejection, canonical distribution operands, protected dependency
constraints, shared check deadline, uncertain index results, npm origin restrictions/newer-version
comparison, and verification of the specific removed pip installation. See [validation](../../validation.md).
