# npm and pip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Добавить global npm и Python distributions выбранного основного Python/venv в apps.

**Architecture:** Новые PackageManager адаптеры используют существующий CommandRunning. RuntimeDiscovery обнаруживает установки; AppModel сохраняет выбор и переключает один менеджер источника через координатор.

**Tech Stack:** Swift 6, macOS 14+, SwiftUI, Foundation/POSIX runner, Python importlib.metadata, установленный npm и pip.

**Spec:** docs/superpowers/specs/2026-11-08-npm-pip-design.md

## Global Constraints

- Без новых зависимостей, sudo и --break-system-packages.
- Один выбранный npm и один выбранный Python; основные установки и venv поддерживаются.
- Реальные пакеты не изменяются во время проверки.
- Изменения выполняются последовательно; чтение источников остаётся независимым.
- Стандартные кнопки окна macOS сохраняются без дублирования.

## Review Focus

- Scoped npm names и JSON с exit code 1 не должны ломать проверку или становиться аргументами другого назначения (задача 1).
- Ссылки npm и direct URL/editable Python не заменяются реестровыми пакетами (задачи 1–2).
- Выбранный venv сохраняет свою идентичность при symlink на общий Python (задача 2).
- Чужие/system/conda distributions и исчезнувший runtime не становятся доступными для изменения (задачи 2–3).
- Подтверждение удаления описывает ровно пакет, источник и окружение; настройка runtime не меняет контекст посреди операции (задача 3).
